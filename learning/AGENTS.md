# Learning Instructions

本目录用于 2026-09-14 至 2026-10-31 的机器人控制与强化学习学习计划。

## Required Context

处理学习相关任务前，优先阅读：

1. ROADMAP.md
2. PROGRESS.md
3. KNOWLEDGE_CHECKLIST.md

涉及训练实验时，再阅读：

4. EXPERIMENTS.md

仓库根目录官方 `AGENTS.md` 中关于 Microduck 源码、训练、测试、
Sim2Real 和代码规范的要求仍然有效。

## Learning Goal

目标是在 2026 年 11 月开始投递机器人控制 /
机器人强化学习相关实习岗位。

主项目：

Microduck PPO locomotion + MuJoCo + Sim2Real。

## Learning Principle

解释知识时优先建立：

数学
→ 控制/RL理论
→ Python/PyTorch实现
→ Microduck源码
→ 实验

之间的联系。

不要把“代码成功运行”视为知识掌握。

## Completion Rule

一个知识点完成至少需要：

- 能用自己的话解释；
- 能完成基本计算或简单代码；
- 能解释它在机器人中的用途；
- 如果与 Microduck 相关，能够指出对应源码或数据流。

## Progress

完成重要学习任务后更新 `PROGRESS.md`。

完成实验后更新 `EXPERIMENTS.md`。

没有证据时，不要把知识点标记为完成。
